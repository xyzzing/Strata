# AMD gfx1100 (RDNA3) HIP port — fork status

> This fork of [Niko1221/Strata](https://github.com/Niko1221/Strata) carries the working HIP port for
> RDNA3 (gfx1100 — Radeon RX 7900 XT/XTX/GRE class). Upstream now ships a HIP backend with an RDNA4
> (gfx1201) lead; this fork maintains the gfx1100 lineage — the patch-table pipeline, the verified
> kernel suite and the measured 7900 XTX work — with pieces proposed upstream one concern per PR.
> Port thread with findings: [Niko1221/Strata#106](https://github.com/Niko1221/Strata/issues/106).
>
> **How this was made:** the port, its verification campaigns and this document were produced by an
> AI engineering agent powered by **GLM-5.3 (Z.ai)** working under
> [xyzzing](https://github.com/xyzzing)'s direction — every number below traces to a recorded
> measurement on this machine. The measured model is **Qwen3.8-Flash-Next** (Qwen team; ISTA-DASLab
> GSQ-RCO IQ3_S compression), served as this machine's local resident (loopback 8081) with its MTP
> draft layer as the speculative-decoding drafter in every decode figure. Full credits at the end.

## What is verified (parity-first)

Every kernel on the default forward path is tested on the card against independent references
before any performance claim is made:

- Kernel suite on gfx1100 — last recorded full runs: **0.1.31: 42 passed / 0 failed / 2 declared
  weight-gated skips; 0.1.33: 53 passed; 0.1.35: 55 passed.** Newer bases build clean, and the arms
  below carry their own parity gates.
- **All ten IQ quantization formats bit-exact** against gguf-py (a second, independent
  implementation in another language); MMQ prefill **8/8** types verified on the card, IQ3_S (the
  model's weight format) included.
- The discipline found and fixed two real forward-path defects (an 80 KB dynamic-LDS overrun and an
  FMA-contract divergence), and records a HIP `__vsub4` saturation divergence vs CUDA for any
  IQ-format mismatch.

## Measured on this machine

Hardware/OS: Radeon RX 7900 XTX 24 GB (gfx1100), Ryzen 9 7900X, 96 GB DDR5, Fedora 44; ROCm 7.1.1
(system) and the 10.2 nightly SDK; the fork's main is the 0.1.39 working line, while the numbers below
were measured on recorded 0.1.31–0.1.38 builds. Model: Qwen3.8-Flash-Next IQ3_S
(46.8 GiB of experts mapped + PLE table + MTP draft) — the model Strata is built around.

Methodology: one-shot, greedy, median of 3 non-stalled cells per tier; stalled cells are recorded,
never dropped. Figures are warm-state (a cold serve climbs ~+35% to these values as the page cache
warms). Every number traces to a record file in the maintainer's local archive (named inline).

| metric | value | record |
| --- | --- | --- |
| decode, 1K→128K context | 56.8–64.2 tok/s (flat — GDN attention is O(1) in context) | `amd-rates-0131-20261001.json` |
| decode, sustained warm serve | 58.1 tok/s | `record-consolidation-20261004.json` |
| prefill @128K, baseline | 1,403 tok/s | `amd-rates-20260930.json` |
| prefill @128K, + gfx1100 hipBLASLt `100500` table | 1,687 tok/s (**+82%** over the tableless 926) | `record-hipblaslt-100500-20261004T103111Z.json` |
| prefill @128K, + `STRATA_HIP_WMMA=1` | 1,863 tok/s (**+22.8%**, 5/5 pairs) | `record-pa-wmma-e2e-verdict-20261004.json` |

## Measured and rejected (records kept)

Everything on the decode critical path has been measured; what did not win is recorded, not
deleted: `--spec-split` (retracted — it *costs* ~27% decode), `--prefill 8192` (0.0%), the
`--pcie-frac` sweep, pool `MT_MULT`, ring-wait pipelining (−0.94%), learned expert placement
(−1.53% on-distribution; conditional on a workload shift), `STRATA_MTP_BATCH_F16`,
`STRATA_VERIFY_DEVICE_PLAN`, the rocWMMA full-scorer (parity-clean but ~2× slower than portable),
and 24 GB full-expert-residency (arithmetically impossible: the smallest whole-pack quant is
63.35 GiB).

## Limits and open work

- The measured context ladder stops at **128K**. The engine supports YaRN beyond that (262K/512K
  knobs are present), but no cell above 128K has been measured on this machine.
- **No same-weights logit reference exists** here (a second ~84 GB-resident reference cannot
  coexist in 96 GB RAM) — the correctness claim rests on the per-kernel parity suites, not on
  end-to-end logits.
- The QSA scorer's portable path is deliberately reference-speed; the tensor-core arms above are
  the opt-in fast paths.
- Open upstream PRs: rates row [#319](https://github.com/Niko1221/Strata/pull/319), decode
  autotune [#744](https://github.com/Niko1221/Strata/pull/744), 7.1.1-vs-nightly benchmark
  [#745](https://github.com/Niko1221/Strata/pull/745), hipBLASLt table
  [#755](https://github.com/Niko1221/Strata/pull/755). Merged: Monitor rate fix
  [#104](https://github.com/Niko1221/Strata/pull/104).

This is personal-infrastructure documentation, not a supported build. Numbers above are from this
one machine; treat them as a datapoint, not a benchmark.
