# AMD gfx1100 (RDNA3) HIP port — fork status

> This fork of [Niko1221/Strata](https://github.com/Niko1221/Strata) carries the working HIP port for
> RDNA3 (gfx1100 — Radeon RX 7900 XT/XTX/GRE class). Upstream now ships a HIP backend with an RDNA4
> (gfx1201) lead; this fork maintains the gfx1100 lineage — the patch-table pipeline, the verified
> kernel suite and the measured 7900 XTX work — with pieces proposed upstream one concern per PR.
> Port thread with findings: [Niko1221/Strata#106](https://github.com/Niko1221/Strata/issues/106).
>
> **How this was made:** the port, its verification campaigns and this document were produced by an
> AI engineering agent powered by **GLM-5.3 (Z.ai)** working under
> [xyzzing](https://github.com/xyzzing)'s direction — every number below traces to a recorded
> measurement on this machine. The measured model is **Qwen3.8-Flash-Next** (Qwen team; ISTA-DASLab
> GSQ-RCO IQ3_S compression), served as this machine's local resident (loopback 8081) with its MTP
> draft layer as the speculative-decoding drafter in every decode figure. Full credits at the end.

## What is verified (parity-first)

Every kernel on the default forward path is tested on the card against independent references
before any performance claim is made:

- Kernel suite on gfx1100 — last recorded full runs: **0.1.31: 42 passed / 0 failed / 2 declared
  weight-gated skips; 0.1.33: 53 passed; 0.1.35: 55 passed; 0.1.40 line (refresh-0140, 2026-10-06):
  86/87 passed + 2 declared skips** (the historically documented `hipblaslt_gemm`/`hcd_exact` class)
  **+ 1 upstream-declared CUDA-only-by-design failure** — the first full-suite run on a 0.1.40 base,
  including **upstream's own `hip_prompt_attn_wmma` parity passing on gfx1100** and the Aurora
  gfx11 fused-expert tests. All ten IQ quantization formats bit-exact on the new line too.
- **All ten IQ quantization formats bit-exact** against gguf-py (a second, independent
  implementation in another language); MMQ prefill **8/8** types verified on the card, IQ3_S (the
  model's weight format) included.
- The discipline found and fixed two real forward-path defects (an 80 KB dynamic-LDS overrun and an
  FMA-contract divergence), and records a HIP `__vsub4` saturation divergence vs CUDA for any
  IQ-format mismatch.

### Closed — measured, and why we are not moving forward

**Headroom did not exist (the phase was already at its limit):**

- **Fused-int8 MoE kernels** (rocWMMA translation of the fused-native arm): fixtures integer-exact
  (rel RMS 0.0), but the engagement cell measured **−0.8% e2e vs the pre-declared ≥+3% gate** — the
  vendored MMQ tiles were already RDNA3-aware, so the generic-tile headroom the translation targeted
  does not exist. Arm ships opt-in dormant + parity-protected (`STRATA_PF_FUSED`, fork `4ce4643`).
- **MMQ tile-J re-dispatch**: the kernel-vs-PCIe counter-split (3 production-stack 128K cells) put
  the routed-tail **transfer floor at 79% of the MoE GEMM cluster — 24.5% of ALL 128K prefill** —
  with 17 of 21 transfer seconds already hidden behind compute. Kernel slack ceiling ≈6.3% prefill;
  a realistic tile win nets ≤2-3% e2e, below the gate. Closed 2026-10-07
  (`record-counter-split-20261007.json`). Re-open only if residency rises materially.
- **Expert GEMMs via hipBLAS(f16)**: 4.1× worse than the MMQ int8-tile family on these shapes —
  MMQ is the correct family on RDNA; the BLAS route is not a path (`STRATA_PREFILL_MMQ=0` bracket).
- **Learned expert placement**: −1.53% on-distribution; conditional on a workload shift that has not
  happened (the conditional-OOD lever stays a paper design).
- **24 GB full-expert residency**: arithmetically impossible — the smallest whole-pack quant is
  63.35 GiB. The decomposition (streamed tail + heat cache) is the only fit.

**Precision contract failed (structural, not tunable):**

- **INT8-Q score path**: rocWMMA int8→i32 dots are integer-exact (4.9e-8 vs double), but the
  pre-declared gates fail on the quantization class — softmax weight Δ **9.5e-2** vs the 2e-2 bound
  under the 12×-outlier activation class (~27% of groups); output Δ 1.55e-1. The fp16 hi/lo incumbent
  is ~2⁻²² ≈ fp64 truth. No kernel integration; fixture `tests/hip/qsa_int8_q_fixture.cu`, verdict
  in `65a3c8f`; broken-reference tripwire mechanized (`116a8e1`). Note: upstream #1367's
  int8-MMA design (raw int8 KV codes + exact int32 accumulate + fp32 softmax) is a *different* class
  and not auto-dead — it stays a ranked pending port, not a rejection.
- **`STRATA_NORM_ROPE=1`**: parity-WRONG on gfx1100 (`rope_parity` 3,644/49,152 + 3,546/98,304
  elements differ) — upstream's HIP-off default gates a real kernel gap on this arch. Never enable.
